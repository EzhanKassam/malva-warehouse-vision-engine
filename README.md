# Malva Warehouse Vision Engine

Python-based computer vision and inventory monitoring engine that ingests mine warehouse camera feeds/video to track vehicle traffic and estimate ready ore stockpiles ready for shipment.

## Features
- Warehouse Vehicle Traffic Tracker (YOLO + ByteTrack)
- Ready Ore Volumetric & Stockpile Estimator
- Annotated Video & Visual Feedback Generator
- Malva Dashboard Payload Orchestrator

## Setup
```bash
pip install -r requirements.txt
```

## Usage
```bash
python main.py
```
